# روز — فضای شخصی من

برنامه‌ریز کارهای روزانه با تقویم شمسی، نصب‌شدنی روی گوشی و لپ‌تاپ (PWA) و همگام‌سازی بین دستگاه‌ها.

**نسخهٔ آنلاین:** https://landmarkvisualstudio-rgb.github.io/rooz-planner/

## همگام‌سازی بین دستگاه‌ها
داده‌ها اول روی خود دستگاه (localStorage) ذخیره می‌شوند و بعد در یک **Gist خصوصی** در حساب گیت‌هابت همگام می‌شوند.

1. [یک توکن کلاسیک با دسترسی فقط `gist` بساز](https://github.com/settings/tokens/new?scopes=gist&description=Rooz%20planner%20sync).
2. در برنامه: تنظیمات ← همگام‌سازی بین دستگاه‌ها ← توکن را وارد کن.
3. روی دستگاه دوم هم همین توکن را وارد کن؛ برنامه همان Gist (`rooz-planner.json`) را پیدا می‌کند.

همگام‌سازی هنگام باز شدن، هر ۳۰ ثانیه، هنگام برگشت به برنامه و بلافاصله بعد از هر تغییر انجام می‌شود. اگر روی دو دستگاه یک کار تغییر کند، تغییر جدیدتر می‌ماند؛ حذف‌ها هم به همهٔ دستگاه‌ها منتقل می‌شوند.

## یادآوری‌ها
سر ساعت یادآوری (به وقت تهران) اعلان نمایش داده می‌شود، به شرطی که برنامه باز باشد (حتی در پس‌زمینه). چون GitHub Pages سرور ندارد، وقتی برنامه کاملاً بسته است اعلان ارسال نمی‌شود.

## توسعه
```sh
npm install
npm test        # قواعد برنامه‌ریز + منطق ادغام همگام‌سازی
npm run build   # خروجی در dist/
```
هر push روی `main` با GitHub Actions ساخته و روی GitHub Pages منتشر می‌شود.
